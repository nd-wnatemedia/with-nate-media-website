# With Nate Media Website

A responsive static website for With Nate Media.

## Pages
- `index.html`: Homepage, services, process, about and contact
- `case-studies.html`: Four client-result summaries
- `styles.css`: Responsive design system

## Publish to Vercel
1. Open https://vercel.com/new and import the GitHub repository `nd-wnatemedia/with-nate-media-website`.
2. Choose **Other** as framework preset. This is a static HTML site; no build command is needed. If prompted, use `.` as output directory.
3. Deploy and review the generated preview URL.
4. Under **Project Settings → Domains**, add `wnatemedia.com` and `www.wnatemedia.com`.
5. Add the DNS entries Vercel provides at your registrar. Preserve existing MX/SPF/DKIM records so email continues to work.

Pushing future edits to the production branch automatically redeploys the site.

## Before public launch
- Integrate your approved logo and brand imagery when supplied.
- Get public-use permission for client names and commercial-result figures; keep the two confidential engagements anonymous.
- Replace the current email CTA with your GoHighLevel scheduling link once supplied.
- Confirm that `nd@wnatemedia.com` accepts incoming email.
- Add appropriate privacy information before introducing forms, analytics, or marketing pixels.

Results are case studies, not direct client testimonials or guaranteed outcomes.
